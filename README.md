# 🖼️ Filtros e Algoritmos de Processamento de Imagens

Repositório desenvolvido para o **Trabalho 1 da disciplina de Processamento de Imagens Digital — UNIOESTE**.

O projeto consiste em um aplicativo desenvolvido em **MATLAB** para aplicar diferentes filtros e técnicas de processamento de imagens, permitindo carregar uma imagem, selecionar um filtro, visualizar o resultado e salvar a imagem processada.

---

## 📌 Sobre o Projeto

Este projeto foi criado com o objetivo de estudar e aplicar técnicas fundamentais de **Processamento Digital de Imagens**.

A aplicação possui uma interface gráfica desenvolvida no MATLAB. Por meio dela, o usuário pode carregar uma imagem local, escolher um filtro disponível e visualizar o resultado diretamente no aplicativo.

---

## 🎯 Objetivo

O objetivo principal do trabalho é implementar e testar filtros clássicos de processamento de imagens, observando como cada técnica altera ou realça características específicas da imagem.

Entre os pontos estudados estão:

- Conversão para escala de cinza;
- Realce de bordas;
- Suavização de imagens;
- Aplicação de ruídos;
- Segmentação;
- Limiarização;
- Equalização de histograma;
- Contagem simples de objetos.
